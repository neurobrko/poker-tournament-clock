# Poker Tournament Clock v0.0.2

A feature release adding a structured tournament editor, player roster tools, and a second-screen tournament dashboard.

## Highlights

- Create reusable tournament templates with structured editing for schedules, purchases, registration, chip values, players, and prize tiers.
- Show the running clock, prizes, and chip values in a read-only dual-screen view.
- Seed tournament rosters from templates; import and export player lists as YAML, with optional aliases and conflict handling.
- Apply roster and settings imports atomically, preserving audit history.

## Upgrade notes

Opening an existing tournament database applies schema migration 5 for player aliases. Back up tournament databases before upgrading. Older schema-4 binaries cannot open a migrated database; restore a pre-upgrade backup to roll back.

## Downloads

GitHub Releases provide standalone executables for Linux, macOS, and Windows on amd64 and arm64. Names use `poker-clock-<os>-<arch>`; Windows files end in `.exe`. See the [README](../README.md) for platform requirements and launch instructions.

These are unsigned raw executables, not installers. Linux needs runtime OpenGL/X11 libraries; macOS builds are not notarized.

## Known limitations

- Fractional display scaling on Linux GNOME (reported on X11 and Wayland) can make the UI incorrectly sized across displays. Setting every display to 100% restores expected sizing in the reported setup; see [known issues](../docs/known-issues.md).
- The app records tournament activity but does not track player chip stacks, deduct blinds or antes, evaluate hands, or determine eliminations automatically.
- Sleep prevention depends on OS and desktop support; the app can pause at its last saved checkpoint if it detects system sleep.
- Fyne audio playback depends on the system audio backend.
