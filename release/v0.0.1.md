# Poker Tournament Clock v0.0.1

First release of Poker Tournament Clock, a self-hosted desktop clock and tournament record keeper for Texas Hold’em home tournaments.

## Highlights

- Run a configurable blind-level and break schedule, with antes, registration deadlines, break reminders, and tiered payouts.
- Manage players, buy-ins, rebuys, add-ons, sit-outs, busts, corrections, and final results.
- Save each tournament in its own SQLite database. Transactional audit history and crash-safe locking help protect tournament records.
- Import and export validated YAML tournament templates; includes an editable default structure.
- Use mouse or keyboard controls in a resizable, fullscreen-capable desktop app. Sound and best-effort sleep inhibition are supported.
- Show the release version in the clock footer; welcome screen identifies Poker Tournament Clock and lists the MIT licence and maintainer contact details.
- Embedded Texas Hold’em rules reference; app runs without a server or external database.

## Downloads

When published by GitHub Actions, release assets are standalone executables for Linux, macOS, and Windows on amd64 and arm64. Names use `poker-clock-<os>-<arch>`; Windows files end in `.exe`. See the [README](../README.md) for platform requirements and launch instructions.

These builds are unsigned raw executables, not installers. Linux needs runtime OpenGL/X11 libraries; macOS builds are not notarized.

## Known limitations

- The app records tournament activity but does not track player chip stacks, deduct blinds or antes, evaluate hands, or determine eliminations automatically.
- Hand resolver and player timeline controls are not implemented yet.
- Sleep prevention depends on OS and desktop support; the app can pause at its last saved checkpoint if it detects system sleep.
- Fyne audio playback depends on the system audio backend.
